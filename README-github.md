**Azura Heat** is an original 2D top-down open-world crime game that runs from a single self-contained HTML file — no build step, no dependencies, no network requests. Explore the fictional city of Port Azura (a 6×5 district grid with a beach and the sea) on foot or by car: steal wheels with **E**, outrun a 0–5 star wanted system as police give chase, watch pedestrians flee and traffic swerve, and take on 3 missions from two contacts — The Docks and Café Azul — for cash. Full HUD with cash, wanted stars and health, a live minimap, and title / pause / BUSTED / DOWNED / MISSION COMPLETE screens. Deterministic mode (`?shot=start|play|end&seed=1`) powers the bundled screenshots.

## Run it

```sh
# The game is one file: game/index.html
# Just open it in any browser — or serve the folder:
npx serve .
# then visit /game/index.html
```

Controls: **WASD / arrows** to move and drive, **E** to enter or exit a car, **P** pause, **M** mute.
